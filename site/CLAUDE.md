# `site/` — generated projection

`site/` is a **generated projection** of `.claude-plugin/marketplace.json`, produced by
`.claude/skills/add-plugin/scripts/sync-site.sh`. It is **never hand-edited**.

Byte-equality between the committed `site/` and what the generator would produce today is enforced by
`tests/gates/18-pages-in-sync.sh`. The gate runs on every push/PR via `ci.yml`.

Published verbatim (no in-CI regeneration) to GitHub Pages by `.github/workflows/pages.yml`.

## How to update the site

1. Edit the manifest (`.claude-plugin/marketplace.json`) or the generator (`sync-site.sh`).
2. Regenerate: `bash .claude/skills/add-plugin/scripts/sync-site.sh`
3. Verify: `bash tests/gates/run-all.sh` (G18 must pass)
4. Commit both the manifest change and the updated `site/` files together.

## Contents

| File | Role |
| ---- | ---- |
| `index.html` | Landing page — one card per plugin (or empty-state) |
| `sitemap.xml` | Single-URL sitemap for the canonical root |
| `robots.txt` | Allows all crawlers; points to sitemap |
| `assets/favicon.svg` | Static brand mark (committed; not regenerated by the generator) |

## Pinned build date

`sync-site.sh` uses a pinned `SITE_BUILD_DATE` constant (never `date`) to keep the generator
deterministic for byte-equality checks. The operator bumps it when re-publishing after content changes.

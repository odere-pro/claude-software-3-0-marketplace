# `docs/plan/` — roadmaps (proposals)

Author-only. This folder holds **phased roadmaps produced by the brainstorm team**
([`../brainstorm/`](../brainstorm/)) — proposals, not decisions. Each roadmap is the input the
`registry-dev` engineering team implements via
[`../../.claude/teams/registry-dev/BACKLOG.md`](../../.claude/teams/registry-dev/BACKLOG.md). See
[`../teams.md`](../teams.md) for the handoff.

- A roadmap follows the structure in [`../brainstorm/TEAM-BRIEF.md`](../brainstorm/TEAM-BRIEF.md) §7
  (context → thesis recap → baseline → constraints → decisions log → phases → quality/performance
  targets → open questions → handover checklist).
- It is a **proposal**: it records decisions and their rejected alternatives but does not, by
  existing, authorize implementation — `registry-dev-manager` and the operator gate that.
- Naming: `NNNN-<slug>.md` (e.g. `0001-agentic-engineering-level-up.md`), produced at brainstorm
  run-time.

Nothing here ships or loads into an end-user session.
